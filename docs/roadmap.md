# Product Roadmap

## Phase 1 — MVP foundation
- Project and document management.
- PDF/DOCX upload and extraction preview.
- Question correction and ordering.
- User-supplied text reference excerpts with provenance and per-run selection.
- Per-question generation, verification, and up to two revisions.
- Manual review and immutable answer history.
- PDF, DOCX, Markdown, and JSON export.

## Phase 2 — Quality improvements
- Better table and multi-column extraction.
- Configurable answer style by course and marks.
- Reference-file upload and richer source-grounded answers.
- Improved evaluation dashboard and reviewer feedback.
- Provider fallback and per-model cost/quality comparison.

## Phase 3 — Advanced capabilities
- Additional input formats based on demand.
- Institution/course templates.
- Batch projects and reusable course libraries.
- Optional semantic retrieval over user-provided reference materials, only if evaluation shows it improves answers.
- Team collaboration and role-based access.

## Roadmap rules
Prioritize measured user pain and evaluation results. Do not add agent frameworks, vector databases, or multi-service complexity merely because they are fashionable. Every phase must retain source provenance, user control, privacy, and transparent AI limitations.
